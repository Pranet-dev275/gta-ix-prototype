# GTA IX - Prototype Game

A playable top-down action game prototype inspired by Grand Theft Auto.

## Features

🎮 **Gameplay Mechanics**
- Top-down 2D gameplay
- Player character with health system
- Enemy AI that hunts the player
- Bullet physics and collision detection
- Money and leveling system

🎯 **Missions**
1. **Eliminate Threats** - Defeat 5 enemies ($500 reward)
2. **Defend the Base** - Survive 30 seconds of enemies ($750 reward)
3. **Steal the Money Bag** - Collect the bag and return to start ($1000 reward)

👥 **NPCs**
- Mission givers scattered across the map
- Each NPC offers a different mission
- Interact by starting missions from the menu

📊 **UI/HUD**
- Real-time health bar
- Money counter and level display
- Mission information panel
- Control instructions

## Controls

| Key | Action |
|-----|--------|
| **WASD** or **Arrow Keys** | Move |
| **Mouse** | Aim |
| **Click** | Shoot |
| **M** | Open mission menu |
| **E** | Interact (coming soon) |

## How to Play

1. Open `index.html` in your web browser
2. Press **M** to open the mission menu
3. Choose a mission (1, 2, or 3)
4. Complete the objective:
   - Mission 1: Kill 5 enemies
   - Mission 2: Survive 30 seconds
   - Mission 3: Get the yellow bag and return
5. Earn money and level up!
6. Take damage from enemy collisions
7. Don't let your health reach 0!

## Game Stats

- **Starting Health**: 100 HP
- **Enemy Speed**: Varies by mission type
- **Bullet Damage**: 10 HP per hit
- **Mission Rewards**: $500 - $1000

## Tips

💡 **Gameplay Tips:**
- Use the space between NPCs to avoid enemy fire
- Complete easier missions first to earn money
- Level up increases your reward multiplier
- Enemies get stronger on higher level missions
- Aim for headshots when possible
